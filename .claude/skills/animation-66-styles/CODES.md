# Codes des 69 styles

Tape le code dans Claude Code, suivi de ton texte (sépare les scènes par `|`). Exemple :

```
/anim-01-neon-nuit Lance ta formation|En *30 jours*|Abonne-toi
```

Options à ajouter à la fin du texte, en langage naturel : format (9:16, 16:9, 1:1, 4:5), voix-off ou musique jointe, logo, couleurs.
