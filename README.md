# site-formation

## Voix off « Le premier pas »

Dossier [`voix-off/`](voix-off/) :

- `voix-off-perle.mp3` : voix off avec la voix Perle d'ElevenLabs (≈ 38 s)
- `voix-off-masculine-tom.mp3` : version masculine générée en local (≈ 58 s)
- `script-voix-off.md` : texte, méthode, résultats et mode d'emploi
- `generer_voix_off.py` : programme de génération locale avec contrôle de l'articulation
- `telecharger_modeles.sh` : téléchargement des modèles nécessaires

## Agent de trading automatique

Dossier [`agent-trading/`](agent-trading/) : agent qui analyse le marché crypto 24h/24, passe des ordres
et protège le capital (stop-loss, limite de perte journalière, coupe-circuit). Mode simulation par défaut.
Voir [`agent-trading/README.md`](agent-trading/README.md).
